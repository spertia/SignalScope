Signal Survey

GPS + Sensor + Time

This prototype models how Wi-Fi coverage could change around Times Square. GPS provides location, a device sensor would record network conditions, and repeated surveys reveal changes over time.

The heatmap is theoretical. It combines logarithmic distance loss from three assumed rooftop access points, additional building attenuation, and higher network demand during crowded periods. It is a visualization model, not a live network test.
